# AGENTS.md

## 项目目标

在现有 Vue + FastAPI 工程上实现“筑智共生 AI Agent”完整产品骨架和最小可运行安全闭环。

## 强制规则

1. 保留现有项目历史和可用配置，先检查再修改。
2. 前端使用 TypeScript，禁止使用 `any` 逃避类型设计，确实无法避免时写注释说明。
3. 后端使用 Pydantic Schema 和 SQLAlchemy Repository，Endpoint 不写业务逻辑。
4. Agent 节点不能处理 HTTP，不能直接创建数据库会话。
5. 默认离线启动，不要求外部 API Key。
6. 模拟结果必须标记 `is_simulated=true`。
7. 无规范依据时不得编造条款。
8. AI 生成的工单是草稿，必须人工确认。
9. 日报数字由 SQL 统计。
10. 质量和绿色模块先建立正式占位页面和状态接口。
11. 每完成一个 Phase 就运行对应测试。
12. 最终必须保证后端测试和前端构建通过。

## 代码风格

- Python：类型注解、清晰异常、短函数、可测试；
- Vue：Composition API、`<script setup lang="ts">`；
- API：统一 envelope；
- 文件名和代码标识用英文，用户界面用中文；
- 业务枚举集中定义；
- 时间使用 ISO 8601；
- 相对路径通过配置计算，不硬编码本机路径。

## 输出要求

任务完成后提供：

- 修改摘要；
- 测试输出；
- 启动说明；
- 演示账号；
- 模拟与真实能力边界。
