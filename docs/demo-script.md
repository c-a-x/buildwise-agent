# 演示脚本

1. 使用 `safety / BuildWise123!` 登录。
2. 打开“安全分析”，选择演示项目，上传任意 jpg/png 图片。
3. 在“离线演示场景”选择 `no_helmet`，提交分析。
4. 查看风险等级、证据、五 Agent trace、整改消息和工单草稿。
5. 点击“确认创建工单”。
6. 在“工单中心”依次推进：`待处理 → 处理中 → 待复核`。
7. 使用 `manager / BuildWise123!` 登录，将工单关闭。
8. 打开“日报中心”，选择项目和日期，点击生成日报并打印/导出。
9. 在“知识库”搜索“安全帽”，查看本地规范证据。

也可以运行后端自动化闭环：

```powershell
cd backend
python -m pytest -q
```
